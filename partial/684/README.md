# Erdős Problem #684 — partial results

**Problem** ([erdosproblems.com/684](https://www.erdosproblems.com/684)). For 0 ≤ k ≤ n write C(n,k) = u·v, where every prime dividing u is ≤ k and every prime dividing v is in (k, n]. Let f(n) be the least k with u > n². Give bounds for f(n). **Prize:** none listed.
**Status of the problem** (as of 2026-11-25): open. The page lists Mahler (f(n) → ∞, ineffective), Tang + ChatGPT (f(n) ≤ n^{30/43+o(1)}; n^{2/3+o(1)} under RH or the density hypothesis), and APSSV (arXiv:2603.29961, internal OpenAI model): f(n) ≤ (24/(π²−6) + o(1))(log n)² ≈ 6.20 (log n)², and arbitrarily large n with f(n) ≥ (1/2 − o(1)) log n. Not yet on the page: Bae (arXiv:2604.23784) proves limsup f(n)/log n · (log log log n/log log n) ≥ 1/2, so f/log n is unbounded; Li (arXiv:2606.08216) proves f(n) = (2/(1−γ) + o(1)) log n ≈ 4.73 log n for almost all n. Only the abstracts and outlines of Bae and Li were read; their theorems are reported, not checked here. Open: the worst case between Bae's lower bound and (log n)², and any effective lower bound valid for all n.

Notation: L = log n; a_p = p − (n mod p) ∈ [1, p], the distance from n up to the next multiple of p.

## Results here
1. **[Proved]** *Kummer form and anchored construction (re-derivation of APSSV's lower bound).* v_p(C(n,k)) = #{j ≥ 1 : n mod p^j < k mod p^j}. For p ≤ K let p^{e_p} be the least power of p exceeding K, M_K = ∏_{p≤K} p^{e_p}, n = M_K − 1. For k ≤ K: if j ≤ e_p then n mod p^j = p^j − 1 ≥ k mod p^j; if j > e_p then n mod p^j ≥ p^{e_p} − 1 ≥ K ≥ k. No carries, so u(n,k) = 1 and f(n) > K. Since log M_K = ψ(K) + θ(K) = (2+o(1))K, f(n) ≥ (1/2 − o(1)) log n. Checked by hand.
2. **[Proved]** *Theorem B: f(n) ≤ (288 + o(1))(log n)²* (weaker than APSSV's 6.20). Let I be the primes in (Y/3, Y/2]. (i) log u(n,k) ≥ Σ_{p≤k} log p·[k mod p > n mod p] (Kummer at j = 1). (ii) For p ∈ I the block k ∈ [p, 2p−1] ⊂ [1, Y] gives a_p − 1 carries, so S := Σ_{k≤Y} log u(n,k) ≥ Σ_{p∈I} (a_p − 1) log p. (iii) Counting lemma (weakest step): a_p ≤ A forces p | n + a_p, and each n + a has at most log(n+A)/log(Y/3) prime factors in I, so #{p ∈ I : a_p ≤ A} ≤ A·log(n+A)/log(Y/3). (iv) Hence S ≥ A(|I| log(Y/3) − A log(n+A)); with |I| log(Y/3) ~ Y/6 and A = ⌊Y/(12L)⌋, S ≥ (1+o(1)) Y²/(144L). (v) Some k ≤ Y has log u ≥ S/Y ≥ (1+o(1)) Y/(144L) > 2L once Y = ⌈(288+ε)L²⌉. ∎
3. **[Proved]** *Lemma C (cost lower bound).* Define cost(n,X) = Σ_{p≤X} log(p/a_p) and excess E(n,X) = cost(n,X) − π(X) (each term averages 1 for random n). If f(n) > K, averaging level-1 carries over k ≤ K gives Σ_{p≤K/3} log p·(a_p/p) ≤ 6L + O(log K), and AM–GM then gives cost(n, K/3) ≥ (1 − o(1))·m·log(K/(18L)) with m = π(K/3). Also checked numerically on all 999,900 n in [100, 10^6).
4. **[Proved]** *Theorems 1–4 (from Lemma C; only these sketches survive in the sources).* (1) The counting lemma bounds cost by (1+o(1))·m·(log 2L + 1), giving f(n) ≤ (36e + o(1))(log n)² ≈ 98 (log n)². (2) The terms of E are uncorrelated over n ≤ N (n mod pq equidistributes for pq ≪ N), so E = o(π) for almost all n and f(n) ≤ (18e + o(1)) log n ≈ 49 log n for almost all n (Li's sharp constant is 4.73). (3) If E(n,X) ≤ θ·π(X)·log log n + O(log n) for X ≤ (log n)^3 with θ < 1, then f(n) ≤ (log n)^{1+θ+o(1)}; the counting lemma only gives θ = 1. (4) Under H(C): E(n,X) ≤ C log n for all X ≤ log n·log log n, f(n) ≤ (3C + o(1))·log n·log log n/log log log n, which matches Bae's lower bound up to the constant. Extreme check: n = primorial − 1 has E/L → 1, so C ≥ 1 is needed.
5. **[Reduction]** *Theorem R.* Let ★_δ be: for all large n, with Y = L^{2−δ}, fewer than 49% of the primes in [Y/2, Y] divide (n+1)(n+2)⋯(n+⌊24L⌋). Then ★_δ implies f(n) ≤ 3L^{2−δ} for all large n. Proof: if f(n) > K = 3Y, Lemma C gives Σ_{p≤Y} log p·a_p/p ≤ 6L + O(log K); on [Y/2, Y], log p/p ≥ log(Y/2)/Y, so Σ a_p ≤ (6L + o(L))·Y/log(Y/2); by Markov at most (1/2 + o(1)) of the band primes have a_p > 24L; each other band prime divides n + a_p with a_p ≤ 24L, contradicting ★_δ. ∎
6. **[Proved]** *Theorem E (exceptional set).* For each fixed c > 1, #{n ≤ N : f(n) > (log N)^c} ≤ N^{1/c + o(1)}. Proof: with the band at Y = (log N)^c/3, let Z(n) = #{band p : a_p ≤ 24L}; the proof of Theorem R shows f(n) > (log N)^c forces Z(n) ≥ (1/2 − o(1))π_band. Take the r-th factorial moment with r = ⌊L/log Y⌋ (so products of r band primes are ≤ N); by CRT each r-set T is fully covered for N·∏_{p∈T}(24L/p) + O((24L)^r) values of n ≤ N; Markov gives #{n : Z(n) ≥ π_band/2} ≤ 2N(96L/Y)^r = e^{L/c + o(L)}. ∎ Consistent with APSSV (count 0 for c > 2), Li and Bae. Novelty checked only against APSSV, Li, Bae and the forum.
7. **[Computed]** *Exact f(n) for all 2 ≤ n < 10^8.* Kummer carry counts on incrementally maintained base-p digits for all p < 1000 (levels with p^j > k reduce to runs of zero digits); near-ties |log u − 2 log n| ≤ 10^{−9} rechecked in long double (one exact tie, u(105,8) = 105²); validated against exact big-integer C(n,k) for all n < 3000 (2998 agree). f(n) is undefined exactly for n ∈ {2–9, 11–15, 17, 19, 20, 23}. Max f/ln n = 9.789 at n = 5,001,874 (f = 151); min for n ≥ 100 is 0.689 at n = 36,315,136 = 2^13·11·13·31 (f = 12). Decade means of f/ln n: 3.227, 3.357, 3.416, 3.460, 3.502 for [10^3,10^4) … [10^7,10^8); about half of all n have prime f(n).
8. **[Computed]** *Excess cost.* For all 10^3 ≤ n < 10^8 and X ≤ 50, max E(n,X)/ln n ≤ 0.99 (at X = 50: 0.99, 0.97, 0.86 over [10^3,10^5), [10^5,10^7), [10^7,10^8)). At X = 400 the max is about 2.8. Correlation of E with f/ln n: 0.30 on random n, 0.47 on a Bae-type family; record holders have E/ln n in [0.16, 0.61] vs a random mean −0.09.
9. **[Computed]** *Families with n < 2^63.* Anchored n = M_K − 1 (5 ≤ K ≤ 25) has actual f 6.5 to 9 times K (f/ln n 3.7 to 5.3); Bae-type n = t·L_M − h − 1 (M = 8…36, t ≤ 4000, h ≤ 5, ~276,000 values) shifts the distribution up (median f/ln n 3.79 → 4.33 from 10^10 to 10^16; random 3.49 → 3.69).
10. **[Heuristic]** *Ingredient audit.* "Residues" a_p = ⌈θ(p)/L⌉ satisfy every fact Theorem B uses (level-1 carries; p | n + a_p; each n + a carries ≤ log(n+A) of log-mass) with no integer behind them, and stall at Y ≈ (16/3)L² ≈ 5.33L². So no argument from those ingredients reaches o((log n)²); APSSV's 6.20 is within 17% of this limit. Trend fits from five decades cannot separate a constant record ratio from slow growth.

## Routes tried and why they failed
- Raising the constant 1/2, or a dichotomy proving f ≪ log n — counterexample: Bae proves f/log n unbounded.
- Legendre's fixed totals Σ_k v_p(C(n,k)) — qualitative wall: they average over all k ≤ n, not k ≤ polylog.
- "Aligned small primes stop large primes" — fails: an adversary can still set large-prime residues cheaply.
- Uniform Ridout / Mahler / subspace theorem — wrong regime: fixed S, ineffective; the naive uniform version is false even for typical n (band part ~ n^{16}).
- Coppersmith, Baker, dual-lattice certificates, product formula — size wall at L²; moments over n — average wall (bound the count, never reach zero; this is what yields Theorem E).
- Nearest open relative of ★: Erdős #890(b), open even for two consecutive integers.
